# Tap sessions

Some steps can only be done by you. A sign-in approval or an email approval exists to prove the person acting is the account holder. If software could pass it, it would protect nothing, and the services treat automated approvals as attacks. There is no bypass. Muse stops at that step and waits for you.

These collect into two short sessions a day, at times you pick. The times are customizable. Muse holds each item ready, you tap or read out the code, and the flow continues. If you miss a session, the items simply wait for the next one.
