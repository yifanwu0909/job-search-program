# Captcha sessions

A captcha exists to tell people and software apart, and Muse is software. Solving one by machine is exactly what the check is built to catch. It breaks the sites' terms, and getting caught risks the account every application lives in. There is no bypass. Muse fills in the application, stops before the captcha, and holds the page for you.

Captchas collect into the same two sessions a day as taps. You solve the puzzle, and Muse submits right away. Most take under a minute, and some days there are none.
