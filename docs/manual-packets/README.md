# Manual packets

A few sites cannot be reached by Muse's browser at all. Some platforms refuse automated browsers on purpose, and some block this machine before any page loads. The block is at the door, so there is nothing inside the flow to fix, and disguising the traffic to sneak past it would risk the application and your account. There is no workaround.

For those jobs, Muse will provide everything you need to complete the application manually: the apply link, your tailored resume, and all the fields for the form. There will not be many of these. Strongly recommended: use the Jobright AI auto application filling plugin. It fills the application in for you. After you submit, tell Muse, and it records the application and watches for the confirmation like any other.
